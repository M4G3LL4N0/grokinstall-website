GrokInstall answers one question honestly: when an agent is told to use a capability, does it need installing at all? If not, it stops. If so, it provisions, verifies and confines. If the safest route needs more authority than the safe policy allows, it refuses and changes nothing.

DECIDE

Three answers, and only three.

Most "set this up" instructions do not need an installation. GrokInstall is built to notice that, and to be unembarrassed about saying so.

INSTALL

Verify before you run it.

Download the binary and the checksum file from the release. Check the checksum first. There is no install script to trust.

Download

gh release download v0.1.1 \
  -p 'grokinstall_0.1.1_darwin_arm64' -p SHA256SUMS

Verify

shasum -a 256 -c SHA256SUMS

Checksums are cross-checked with an independent implementation before publishing.

Use

./grokinstall_0.1.1_darwin_arm64 inspect \
  https://github.com/sharkdp/bat
